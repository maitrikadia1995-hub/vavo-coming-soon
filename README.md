# VAVO — Coming Soon Website

GitHub Pages-ready static website for **VAVO**.

## Folder structure

```text
vavo-coming-soon-github/
├── index.html
├── README.md
├── css/
│   └── style.css
└── images/
    ├── garden-background.jpg
    └── vavo-logo.png
```

## Important

- `images/vavo-logo.png` is the VAVO logo supplied by you.
- `images/garden-background.jpg` is used only as the plant/garden background.
- Website text, headings, categories, links, buttons and icons are HTML/CSS.
- The background does NOT need to contain the website text.
- Edit `index.html` whenever you want to change names, spelling, content or links.
- Edit `css/style.css` for colors, spacing and design.

## GitHub Pages

Keep `index.html` in the repository root.

GitHub:
**Settings → Pages → Deploy from a branch → main → / (root)**

Your existing custom domain can remain configured.

## Main editable sections in index.html

- VAVO website title
- Navigation links
- Main heading
- Description
- Indoor Plants
- Outdoor Plants
- Flowering Plants
- Ayurvedic & Herbal Plants
- Garden Plants
- Home Delivery
- Social media links
- Footer
- Privacy Policy / Terms / Contact links
